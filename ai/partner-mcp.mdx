The partner MCP server lets an agent read your partner account. Your team asks
in plain words, and the agent answers from the same objects the
[Partner API](/partner/introduction) serves:

- Which companies are still waiting on a document?
- What stage is the EIN order for Acme LLC at?
- What would a Delaware LLC with an EIN and a registered agent cost us?
- Why did our endpoint never get `company.incorporated` yesterday?
- What does the March statement come to, and which companies are behind it?

The server only reads. It cannot form a company, place an order, or submit a
filing. See [What it cannot do](#what-it-cannot-do).

This is not the [docs search server](/ai/coding-agents#docs-search-mcp), which
searches these pages and calls nothing.

## Connect

The server is at:

```text
https://mcp.clemta.partners
```

Add it to your client. There is no key to paste: the first time the client
connects, it opens the [partner dashboard](/partner/dashboard) in your
browser, and you approve the connection there.

## What a connection is

Approving creates an **MCP connection** in the partner dashboard: which
agent, approved when, in which mode, last used when.

- **Read-only.** The agent can look things up. It cannot change anything.
- **Sees what your account sees.** A connection covers all your companies.
  Use a test connection while you try things out.
- **Logged.** Every lookup shows in the dashboard's
  [Logs](/partner/dashboard#logs), next to your integration's requests.

There is no API key to copy or keep safe. Clemta creates one for the
connection, and it does not appear in your API key list.

## Revoke a connection

Delete the connection in the partner dashboard. The agent loses access on its
next question and tells you the connection is no longer valid.

Removing the server from your MCP client does not delete the connection.
Delete it in the dashboard too if you are done with it.

## What it cannot do

The agent cannot:

- create or update an account or a company
- place, cancel or pay for a service order
- submit or sign a tax filing, or fulfill a requirement
- create, re-enable or delete a webhook endpoint
- move a test company with the sandbox

Do these with the API or in the partner dashboard.
